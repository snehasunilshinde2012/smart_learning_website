AI-Based Smart Learning System — Website

FILES
- index.html: website structure
- style.css: layout and visual design
- script.js: student performance analysis logic

HOW TO RUN
1. Extract the ZIP file.
2. Open the smart_learning_website folder.
3. Double-click index.html.
4. Enter a student's name, marks, daily study hours, and attendance.
5. Click "Analyze my learning" to see the result.

No installation or server is required. The website works in a modern browser.
The logic is rule-based and AI-inspired; it is not a trained machine-learning model.
Student entries are processed in the browser and are not sent to a server.
